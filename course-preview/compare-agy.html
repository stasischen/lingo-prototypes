# 課程簡報：韓語 A1 第 7 課「向同輩借用文具」

課綱：`ko.a1.l007` / `outline:c:theme02:borrow-familiar-item:ko`

## 學習目標（can-do）

學習者能向同輩借用一件熟悉的文具，理解對方的允許或婉拒，並完成簡短的物品交接與致謝。

## 對象與情境

- **學習者**：成人初學者，說明語言為繁體中文（台灣）。
- **先備知識**：
  - 前面課堂已學過物品代名詞與指定「이건 / 그건」、肯定與否定存在「있어요 / 없어요」、第一人稱所有格「제」、舊詞槽「책」「가방」以及同輩社交稱呼「人名＋씨」。
  - 熟悉基礎日常禮貌體（해요體）的陳述句與疑問句。
- **情境設定**：
  - 在語言交換學習活動的自習教室中，桌上散落著講義與文具，Yuna 和 Minsu 正在各自練習寫作與筆記。
  - 彼此因為手邊缺少文具，自然地向對方開口借用筆記本、橡皮擦、剪刀、尺等，對方依自身狀況答應並遞出物品，或因正在使用而禮貌婉拒。
- **講者設定**：
  - `yuna`（女性）：成人韓語學習者。
  - `minsu`（男性）：成人同儕學習者。
  - 兩人為平輩同學，全程使用日常禮貌體（해요體）。

## 本課要教的文法

| ID | 本課要學會的範圍 |
|---|---|
| `ko.g.request.seyo#c01` | 動詞敬語請求「-(으)세요」，本課聚焦在固定核心請求短塊「[物品] 좀 빌려 주세요」，用以禮貌請求借用物品。 |

### 會用到的舊文法（不出新題，作為會話支撐）

- `ko.g.itda.relational-have#c02`：持有物存在句「[物品]이/가 있어요 / 없어요」，確認手邊是否有某文具。
- `ko.g.focus.additive#c01`：添加助詞「-도」，例如「연필도」「풀도」。
- `ko.g.topic.aboutness#c01`：主題標記「-은/는」，用於對比或轉移焦點，例如「노트는 없어요」「가위는 지금 써요」。
- `ko.g.case.object#c01`：受格助詞「-을/를」，如「연필을 빌려줘요」「책을 빌려요」。
- `ko.g.address.social-choice#c02`：平輩同儕社交稱呼「人名＋씨」，如「민수 씨」「유나 씨」。
- `ko.g.eo.statement#c01` / `ko.g.eo.question#c01`：日常禮貌體陳述與是非疑問句。

## 本課要用到的詞

### 必用詞（課綱 13 個核心詞，均出現在會話輪中）

- **文具名詞**：
  - `ko:n:공책`（筆記本、練習簿）
  - `ko:n:지우개`（橡皮擦）
  - `ko:n:필통`（鉛筆盒、筆袋）
  - `ko:n:자`（尺）
  - `ko:n:가위`（剪刀）
  - `ko:n:수첩`（隨身手冊、小記事本）
  - `ko:n:테이프`（膠帶）
  - `ko:n:풀`（膠水、漿糊）
  - `ko:n:볼펜`（原子筆）
  - `ko:n:연필`（鉛筆）
  - `ko:n:노트`（筆記本、筆記）
- **核心動詞**：
  - `ko:v:빌리다`（借入，說話者主動借進來）
  - `ko:v:빌려주다`（借出，把東西借給他人）

### 補充主題詞與情境短塊

- 固定交接短塊：
  - 「[物品] 좀 빌려 주세요」（請借我某物）
  - 「네, 여기 있어요」（好的，在這裡）
  - 「미안해요. 안 돼요」（不好意思，不行）
  - 「고마워요」（謝謝）
- 情境支撐詞：
  - `ko:adv:좀`：表示客氣委婉的「稍微、請」。
  - `ko:n:책`：前課已學熟悉詞槽，用於示範書本借閱與借入概念。
  - `ko:adj:미안하다`、`ko:adj:고맙다`：日常禮貌應答必備。
  - `ko:v:되다`（안 돼요）：拒絕時自然委婉的表達。

## 範圍限制

1. **情境單純化**：嚴格限定在同輩之間借用文具的短暫交接，不涉及歸還期限、押金、租金或金錢交易（禁止出現 `돈`、`사다` 等）。
2. **借入與借出角色分明**：
   - 借入方表達「借進來」：使用「[物品] 좀 빌려 주세요」或「[主詞]이/가 [對象]한테 [物品]을/를 빌려요」。
   - 借出方表達「借給對方」：使用「제가 [物品]을/를 빌려줘요」或直接交接「네, 여기 있어요」。
3. **禮貌婉拒原則**：拒絕時使用自然得體的日常禮貌體「미안해요. 지금 써요. 안 돼요.」，不使用過於生硬或冷淡的拒絕詞。
4. **語體一致**：全程維持日常禮貌體（해요體），不混雜敬語格式體（합니다體）或半語（해體）。

## 份量規劃

- **句子數**：19 句（限制範圍：12–26 句）
- **對話輪**：14 輪（限制範圍：8–18 輪）
  - Scene 1（順利借用）：5 輪
  - Scene 2（婉拒與替換借用）：9 輪
- **教學卡**：3 張（限制範圍：3–5 張）
  - TC1（structure）：動詞請求短塊「-(으)세요」與「빌려 주세요」
  - TC2（usage）：借用文具的成套交接短塊（請求、答應、婉拒、致謝）
  - TC3（contrast）：借入「빌리다」與借出「빌려주다」的視角與角色區分
- **練習題**：9 題（限制範圍：8–12 題）
  - 包含 3 題填空（cloze）、3 題選擇（multiple_choice）、3 題重組（chunk_assembly），充分覆蓋核心句型與文具詞彙替換。
